# TagAppVault

Ported server spcific media stuff of TagApp5.0.

## Current Stack

| Category             | Technology                             |
| -------------------- | -------------------------------------- |
| **Server**           | Hono                                   |
| **Web**              | Vite React (wouter with useHashRouter) |
| **Database**         | JSON with LowDB                        |
| **State Management** | Jotai + Constate                       |
| **Styling**          | Tailwind CSS                           |
| **UI Components**    | Shadcn UI                              |
| **Media Server**     | Caddy                                  |
